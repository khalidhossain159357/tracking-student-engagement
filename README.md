# Student Engagement & Subscription Analysis

## Project Overview
This project analyzes student engagement on an online learning platform by examining video watch time, subscription status, certificate completion, and engagement patterns across 2021 and 2022.

The analysis combines SQL, Excel, and Python to prepare the data, compare student groups, evaluate statistical relationships, and build a predictive model for certificate completion.

## Business Questions
- How does student engagement differ between paid and free students?
- Did engagement patterns change between 2021 and 2022?
- Is student engagement associated with certificate completion?
- Are engagement patterns across years dependent on one another?
- Can minutes watched be used to predict the number of certificates earned?

## Tools Used
- MySQL
- Microsoft Excel
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Scikit-learn

## Project Workflow

1. Prepared subscription data and identified whether students were active during Q2 2021 and Q2 2022.
2. Calculated total video engagement in minutes for each student and separated paid and free users.
3. Combined engagement data with certificate information for further analysis.
4. Examined engagement distributions and removed extreme outliers.
5. Compared engagement patterns across years and subscription groups using statistical tests.
6. Evaluated the relationship between engagement and certificates earned.
7. Analyzed year-to-year engagement dependency using probabilities.
8. Built a regression model to estimate certificates earned from minutes watched.
